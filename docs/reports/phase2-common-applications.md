Uploaded dependencies are never installed on the editor or selected through its node_modules.
- Profile selection prefers a candidate satisfying the complete declared set. Client imports use the verified browser dependency closure with nested package locations. Uploaded npm lock versions/integrities must match reached dependencies and required/present optional peers. Missing required peers fail; absent optional peers are skipped. Tooling is not automatically a client root. Unknown imports and paths outside the trusted profile fail.
- Static Vite interpretation recognizes finite literal object/array aliases and `path.resolve('./src')` / `path.resolve(__dirname,'./src')`, imported default/namespace/named path bindings, and no-argument arrow factories returning literal config. It does not execute these modules. Literal server/preview `open`/`port` hints are reported **preserved, not applied**. Proxies, dynamic configuration and uploaded executable plugins remain unsupported.
- Tailwind4 uses the selected pinned compiler with existing defaults and finite literal root `@theme`; numeric literal rgb/hsl/oklch-family values are admitted. Nested/dynamic var/url/calc/directives, Tailwind3 config, uploaded PostCSS plugins and UnoCSS are not supported. This is not a nominal parser claim for those tools.
- HTTP compilation preserves CSS HTTP(S) resource references and finite image/font data URLs without fetching them; URL userinfo is rejected. Remote JavaScript remains refused. Linux default egress denial remains effective, so URL preservation does **not** imply asset availability.
- Named text metadata has a separate16KiB strict UTF8 grammar: finite EditorConfig keys, two boolean npmrc hints (`strict-peer-dependencies`, `shell-emulator`), finite formatter fields/globs, and bounded `.env.example[-suffix]` public placeholders/loopback/reserved-domain values. Secret key names, known credential patterns even in comments, URL auth/query/fragment, duplicate npm/env entries, controls and unrecognized values fail. These files stay byte-exact and are never applied or injected into preview environment. This finite grammar is not a universal secret scanner or blanket dotfile allowance. Other files retain the original extension/path policy.
- Raster mode changes no longer restart the capture effect. Current callback refs avoid stale mode closures. A queued pointer can use a newer capture sequence only for **identical PNG bytes, generation, accepted revision, route and viewport** within the same connection epoch. Server-side fresh authority and sequence checks remain. Changed pixels/geometry/authority still reject; PNG equality does not establish hidden DOM equality.

Archive limits remain25MiB compressed,40MiB expanded,2MiB/member,2,000 entries and100:1 ratio, with original path/NFC/link/type/encryption/CRC/encoding/secret/resource checks. No refused member is silently removed. Yarn classic/Berry, Bun text/binary locks and uploaded package-manager hooks remain unsupported. Supported npm lock formats are one package-lock v2/v3, or no lock with disclosed deterministic profile versions satisfying declared ranges.

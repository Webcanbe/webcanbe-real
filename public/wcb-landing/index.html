Questions about ownership

Are these static templates?

Marketplace listings are versioned working projects. Check the listing for the included source and compatibility before choosing a release.

Do visual edits change the real source?

Supported visual changes update the working project source. Use Code mode for changes outside the visual editor’s supported controls.

What happens after I start from a project?

Sign in and follow the selected release’s purchase or access flow. Available releases can become an editable working copy in your workspace.

Can I export the code?

Export your current source from the workspace and continue in your own development tools.

Can a published release silently change?

No. Published releases are immutable; a new release is a separate version.

Does Webcanbe need to stay in the runtime?

Exported source is designed to run independently. Review the project’s own setup instructions and dependencies.
